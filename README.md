# Mareas IHM Pro 11.0.0

Aplicación Android y Wear OS con swipe lateral y scroll vertical.

Pantallas: inicio, mareas +24h, tiempo, viento, mar, UV, playa, pesca y luna/coeficiente.

Artefactos GitHub Actions:
- Mareas-IHM-Pro-APK: APK instalable de prueba con nombre legible.
- Mareas-IHM-Pro-AAB-SIN-FIRMAR: App Bundle de release que debe firmarse con una upload key antes de subir a Google Play.

La etiqueta instalada es `Mareas IHM Pro`; `debug` describe el tipo de compilación y ya no aparece en el nombre del archivo entregado.
